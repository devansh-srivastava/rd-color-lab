# RD Color Lab

Level 1 of a two-player color sorting game. This first version runs offline on one device: use **Play as** to switch between Devansh and Ridhima. Only your station and the shared tube can be used. Sort every color into a full private tube and leave the shared tube empty.

## Run locally

```bash
npm ci
npm run dev
```

Open the URL Vite prints. Use `npm test` to replay the verified level solution and `npm run build` to check the production bundle.

Sound and background music start on the first tap, as required by phone browsers. The music button mutes both and remembers that choice.
